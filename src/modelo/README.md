# Modelo

El [catálogo](catalogo/README.md) lee las fichas y las entrega al
[consultorio](clinica/README.md). La [misión](mision/README.md) recibe un
objetivo al aceptar el caso y devuelve un resultado. El modelo mantiene las
reglas de atención, supervivencia y cobro. Sus contratos se pueden implementar
y comprobar con datos de ejemplo desde consola.
